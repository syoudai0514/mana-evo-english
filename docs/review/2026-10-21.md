# 横断レビュー（2026-10-21）

対象：React 18 / Vite、21画面、学習ロジック、音声接続、Edge Function、PWA、CI。
基準：初回から迷わず開始できること、子供と大人それぞれの動機、記録の正直さ、継続開発のしやすさ。

| 優先度 | 発見・根拠 | 対応方針 |
|---|---|---|
| P1 | App の起動が子供の profile 未作成なら常に Setup。大人単独で開始不可 | 初回から Who で選択、子供登録を独立 |
| P1 | LoginCard は Parent 内だけ。大人の AI 接続設定に子供画面が必要 | 大人設定にも同じログイン部品を提供 |
| P1 | Home に story / world の未実装ボタンを配置 | 遊べるモードを優先、準備中の機能を主導線から除外 |
| P1 | AdultHome の単独ステップ起動が count / minutes を失う | 表示した plan step をそのまま実行 |
| P1 | predictScore は8問から未回答パートも補完し10〜990に換算。Part 1/6/7 不在 | UI を参考値と明記。全パート問題・校正を別 Issue |
| P1 | PIN は localStorage 平文、計算問題で再設定可 | 誤操作防止として正しく説明。強い保護は後続 Issue |
| P1 | Edge rate limit はプロセス内 Map。トークンにモデル制約なし | 本番強化 Issue。デプロイ済み設定・実トークン権限は未検証 |
| P2 | 480px固定、画面ごとの inline style と選択肢過多 | 共通シェル・ホームの2カラム・テーマを整備 |
| P2 | 入力ラベル関連付け・focus・動きを減らす設定が不十分 | 変更画面と共通部品で対応 |
| P2 | Talk.jsx 1,125行。音声、接続、画面、記録が密結合 | リファクタリング Issue。今回音声の全面書換えは行わない |
| P2 | ローカル保存のみ。子供の saveState は保存失敗を握りつぶす | 保存失敗通知を改善。クラウド同期は既存 #1 を継承 |
| P2 | service worker は画像を固定 URL で cache-first | 更新・オフライン範囲・実機復帰を後続検証 |

## 良い土台
純粋関数に分かれた学習状態、既存33テスト、子供/大人の保存領域の分離、音声の復旧処理、会話から復習カードへの接続、子供の「累積できた」を重視する設計は活かす。

## 検証の境界
ローカルのコードレビューと mock ブラウザ検証が対象。本番の Gemini モデル可用性、利用料金、音声品質、Supabase の実 RLS・設定は認証情報なしでは確認できない。README の「無料・上限なし」は根拠として採用しない。
