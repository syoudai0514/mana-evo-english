# [教材 P1] 大人の会話72場面×3難度：話して使える216レッスン

## 制作数
- 日常/仕事/旅行/人間関係/子育て/TOEIC業務場面の6分野×12場面＝72場面。
- A1/A2/B1の3段階＝216レッスン。各レッスンは目標3・モデル会話6〜10発話・自分の話にする質問3・言い換え3・復習フレーズ5。
- 初回は6分野各1場面×A1/A2＝12レッスン。次に各分野4場面、最後に全72場面×3難度。

## 実装の場所
src/data/adult.js の ADULT_COURSES / 会話プロンプト、AdultHome の場面選択、Talk の結果→復習接続。

## 完了条件
- 会話のゴールを「自己紹介で2つ伝える」など観察可能にする。秒数だけで学習完了としない。
- 答えの暗記ではなく実生活の言い換え、聞き返し、助けを求める表現を含める。
- CEFRは制作上の目安で認定結果と表示しない。
- 自由会話/ガイド会話を区別し、話した事実からカード生成する。架空の個人情報を記憶に混入させない。

## 共通の受入条件・引き継ぎ
- `docs/HANDOFF.md` と `docs/CONTENT_SPEC.md` を先に読む（体験刷新 PR のブランチに追加）。Issue に指定した最小バッチから進める。
- ID は固定し、出典・権利・難易度・学習目標・想定時間・日本語訳・レビュー状態を付ける。AI 生成だけで reviewed 扱いにしない。
- 最初のバッチをアプリに接続して検証してから増産。件数チェック、重複、答えの一意性、訳、音声との一致を確認。
- npm test / npm run build と変更範囲のブラウザ確認を実施。未検証の音声や本番接続は明記。
- 完了数/目標数、変更ファイル、検証コマンド、次の最小タスクを docs/HANDOFF.md に記録してコミット。モデルが変わってもこの Issue 単位で再開できる状態にする。
