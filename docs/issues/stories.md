# [教材 P3] お話づくり24話・世界の友達12場面を段階的に実装

## 現状
story/world は未実装。刷新ホームでは押しても遊べないカードを主導線から外している。教材だけ追加して ready にしない。

## 制作数と順序
1. storyの選択→分岐→完了→再開を1話で実装・検証。
2. お話24話（6テーマ×4話）、各話3場面・各場面2択・結末2種・音声/日本語救済。初回3話。
3. worldは架空の友達12場面（6地域×2場面）。初回2場面。実在の子供と通信しない架空の会話として説明。

## 完了条件
- 全分岐で完了できる。間違いで閉じ込めない。個人情報を要求しない。
- 地域/文化をステレオタイプで表現しない。現地の生活の多様性をレビュー。
- 公開前の機能を報酬として約束しない。完成・実機確認後に mode.status とホーム導線を変更。
- 既存のレベル4上限とworld解放条件を整合させる。

## 共通の受入条件・引き継ぎ
- `docs/HANDOFF.md` と `docs/CONTENT_SPEC.md` を先に読む（体験刷新 PR のブランチに追加）。Issue に指定した最小バッチから進める。
- ID は固定し、出典・権利・難易度・学習目標・想定時間・日本語訳・レビュー状態を付ける。AI 生成だけで reviewed 扱いにしない。
- 最初のバッチをアプリに接続して検証してから増産。件数チェック、重複、答えの一意性、訳、音声との一致を確認。
- npm test / npm run build と変更範囲のブラウザ確認を実施。未検証の音声や本番接続は明記。
- 完了数/目標数、変更ファイル、検証コマンド、次の最小タスクを docs/HANDOFF.md に記録してコミット。モデルが変わってもこの Issue 単位で再開できる状態にする。
