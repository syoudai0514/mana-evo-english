# [教材 P1] TOEIC オリジナル600問：全7パート3セットと日本語解説

## 前提
全7パート基盤 [#5](https://github.com/syoudai0514/mana-evo-english/issues/5) のスキーマと素材共有を先に確定する。公式教材の転載をせずオリジナル制作。

## 正確な件数
200問×3セット＝600問。各セット Part1=6 / Part2=25 / Part3=39 / Part4=30 / Part5=30 / Part6=16 / Part7=54。
全体では18/75/117/90/90/48/162問。Part3は各13会話、Part4は各10説明文、Part6は各4文書。Part7は現行仕様を一次資料で確認し単一/複数文書を配置する。
- 最初の小バッチ30問：2/4/6/3/5/4/6問。Part7は3問×2素材、Part3は2会話。3難度の比率・狙うスキルを制作前に一覧化。
- 第1セットは練習用、第2・3セットは未見の模試用に隔離。復習で模試問題を先に見せない。

## 各問の納品物
本文/設問/選択肢/正解/根拠箇所/全選択肢の解説/日本語訳/skill/難度/想定時間/素材ID/著作権情報。
音声台本・話者・アクセント・画像altを付け、設問と音声の完全一致を確認。

## 完了条件
- 正解が一意、語法と文法は二次レビュー。数字・日付・価格を含む設問は計算も検証。
- 問題数だけで「TOEICスコア予測ができる」としない。換算には別途実受験者データの校正が必要。
- scriptでpart別件数、共有素材参照、重複、正解範囲、空の訳/解説を検出。

## 共通の受入条件・引き継ぎ
- `docs/HANDOFF.md` と `docs/CONTENT_SPEC.md` を先に読む（体験刷新 PR のブランチに追加）。Issue に指定した最小バッチから進める。
- ID は固定し、出典・権利・難易度・学習目標・想定時間・日本語訳・レビュー状態を付ける。AI 生成だけで reviewed 扱いにしない。
- 最初のバッチをアプリに接続して検証してから増産。件数チェック、重複、答えの一意性、訳、音声との一致を確認。
- npm test / npm run build と変更範囲のブラウザ確認を実施。未検証の音声や本番接続は明記。
- 完了数/目標数、変更ファイル、検証コマンド、次の最小タスクを docs/HANDOFF.md に記録してコミット。モデルが変わってもこの Issue 単位で再開できる状態にする。
