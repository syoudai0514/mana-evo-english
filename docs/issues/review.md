# [教材 P2] 復習240フレーズ・シャドーイング60文の基礎パック

## 制作数
- 日常/仕事/旅行/子育て/聞き返し/意見表明の6分野×40＝240フレーズ。
- 各分野10＝60シャドーイング文。A1/A2/B1各20文、5〜14語を基本にする。
- 初回：各分野5＝30フレーズ＋各分野2＝12文。

## 納品仕様
en/ja/使用場面/不自然な直訳例と理由/言い換え/音声/関連lesson ID。シャドーイングは強勢・区切り・連結の注釈を追加。

## 実装の場所
src/lib/adult.js のカード/SRSと shadowSentences、Review / Shadow。会話由来のカードと基礎パックはsourceを区別し、全240枚を自動で復習待ちにしない。

## 完了条件
- 初回に1日3/5/10枚から選ぶ、期限分を優先、スキップ/削除/誤り報告。
- 同義のカードを統合しても本人の会話由来データを消さない。
- 文字起こし一致率は発音スコアではない。音素評価を入れるまで誤った採点表示をしない。
- 音声が使えなくても文字で復習が成立し、復習だけの日も学習履歴に残る。

## 共通の受入条件・引き継ぎ
- `docs/HANDOFF.md` と `docs/CONTENT_SPEC.md` を先に読む（体験刷新 PR のブランチに追加）。Issue に指定した最小バッチから進める。
- ID は固定し、出典・権利・難易度・学習目標・想定時間・日本語訳・レビュー状態を付ける。AI 生成だけで reviewed 扱いにしない。
- 最初のバッチをアプリに接続して検証してから増産。件数チェック、重複、答えの一意性、訳、音声との一致を確認。
- npm test / npm run build と変更範囲のブラウザ確認を実施。未検証の音声や本番接続は明記。
- 完了数/目標数、変更ファイル、検証コマンド、次の最小タスクを docs/HANDOFF.md に記録してコミット。モデルが変わってもこの Issue 単位で再開できる状態にする。
