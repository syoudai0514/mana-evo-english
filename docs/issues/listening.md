# [教材 P2] 聞く学習36エピソード：会話・仕事・旅の各12本

## 制作数
- 日常/仕事/旅行各12本＝36本。各分野 A1/A2/B1を4本ずつ。1本3〜6分。
- 各本：6〜12発話の主会話＋ゆっくり復唱＋重要表現5＋確認3問＝180表現枠/108確認問題。
- 初回は各分野A1/A2を1本ずつの6本。残りは6本単位。

## 実装の場所
src/data/train.js、src/lib/episodes.js / episodeStore.js / player.js、Train / TrainPlayer。

## 完了条件
- 台本と音声の文ごとのタイミングが一致。通常速度/低速でも字幕の同期が破綻しない。
- 取得済み/準備中/通信必要を明示。ダウンロード済み素材はオフラインで検証。
- 画面ロック・割込・再開・途中保存・連続再生をiOS実機で確認し結果を記録。
- 既存の自分の会話から作る番組と編集済み教材を区別。録音/合成音声の権利とコストを記録。

## 共通の受入条件・引き継ぎ
- `docs/HANDOFF.md` と `docs/CONTENT_SPEC.md` を先に読む（体験刷新 PR のブランチに追加）。Issue に指定した最小バッチから進める。
- ID は固定し、出典・権利・難易度・学習目標・想定時間・日本語訳・レビュー状態を付ける。AI 生成だけで reviewed 扱いにしない。
- 最初のバッチをアプリに接続して検証してから増産。件数チェック、重複、答えの一意性、訳、音声との一致を確認。
- npm test / npm run build と変更範囲のブラウザ確認を実施。未検証の音声や本番接続は明記。
- 完了数/目標数、変更ファイル、検証コマンド、次の最小タスクを docs/HANDOFF.md に記録してコミット。モデルが変わってもこの Issue 単位で再開できる状態にする。
