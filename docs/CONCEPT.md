# mana-evo-english コンセプト

最終更新: 2026-10-17

## 1. 目的

- 年長の子どもが、**毎日5分ほどモンスターと英語でおしゃべり**して、「単語を言える」から「やりとりができる」へ進むこと
- 英語が苦手な保護者も、記録と訳を見ながら**一緒に覚えられる**こと
- mana-evo の英語部分に特化した姉妹アプリとして、モンスターや進捗をつなげていくこと

## 2. 前提

| 項目 | 決定 |
|---|---|
| 端末 | iPhone（mana-evo と同じ端末）、ホーム画面に追加する PWA |
| AI | Gemini API **無料枠**。Flash-Lite 系（3.1 Flash-Lite を想定）。モデル名は設定で差し替えられるようにする |
| 個人情報 | 会話の中身は日常の話題だけ。無料枠の規約（データが改善目的に使われうる）は了承済み。それでも名前・住所・園名などは AI に送らない設計にする |
| 文字 | 子どもはひらがな・カタカナが読める → ヒントは「絵＋カタカナ読み＋音声」 |
| mana-evo との関係 | 最初は**モンスター画像を借りるだけ**。Supabase を使ったデータ連携は issue で別途進める |

## 3. 子どもが段階的に進む流れ

1. 聞いて分かる（Yes/No、指差し）
2. 選んで答える（"Dog or cat?" → "Dog!"）
3. 単語で答える → AI が文にして言い直す
4. 決まった言い回しの中身を入れ替える（I like ___ / I want ___ / Can I ___?）
5. 自分で文を作る

アプリは2〜4の段階の繰り返し量を毎日確保することに集中する。

## 4. 会話の作り方：台本＋AIのハイブリッド

### 台本（アプリが持つデータ）

- **場面**：あいさつ／好きな動物／朝ごはん／お天気／色／今日なにした？ など
- 場面ごとに**練習する言い回しを2〜3個**、質問を3〜5個、締めのセリフ
- ヒント選択肢（絵文字か画像＋英語＋カタカナ読み＋音声）
- 同じ場面が日を空けて何度も出てくる（言い回しを間隔をあけて復習する）

### AI の役割（Gemini）

- 子どもの返事（音声）を聞き取る。単語だけ、日本語混じり、発音があいまいでもOK
- **言い直して返す**（間違いだと言わず、正しい英語で言い返す）
  - 子「どっぐ！」→ "Oh, you like **dogs**! Me too! What color is your dog?"
- 台本の次の質問へ自然につなぐ。話題がそれたら優しく戻す
- 応答は JSON で受け取る：

```json
{
  "child_said": "dog",
  "reply_en": "Oh, you like dogs! Me too! What color is your dog?",
  "reply_ja": "犬が好きなんだね！ぼくも！きみの犬は何色？",
  "used_target": true,
  "next_step": "ask_color",
  "hint_options": [
    { "en": "brown", "kana": "ブラウン", "emoji": "🟤" },
    { "en": "white", "kana": "ホワイト", "emoji": "⚪" }
  ]
}
```

- 毎回送るのは「場面の指示＋今日の言い回し＋直近3〜4往復」だけ。トークン数を小さく抑える

### AI が使えないとき

- 無料枠の上限、通信エラー、タイムアウトのときは**台本だけで進むモード**に自動で切り替える（ヒントボタンを選んで進む）
- 子どもの体験が止まらないことを優先する

## 5. 無料枠で回すための設計

- 1回の会話は**最大およそ15往復**、1日の回数にも上限を設定する（値は設定で変えられる）
  - 無料枠の1日あたり・1分あたりのリクエスト数制限は Google AI Studio で最新の値を確認し、それより十分小さく設定する
- 音声は「おしてはなす」で区切った短い録音だけを送る（長くても5〜8秒程度）
- **APIキーはアプリ内に置かない**。Supabase Edge Function を中継に使い、キーは Edge Function の secret に置く
  - 中継は Supabase のログイン（JWT）がある人だけ使える → 他人に無料枠を使われない
  - 中継側でも1日の上限を数えて超えたら止める

## 6. 声まわり（iPhone PWA）

| | 方針 |
|---|---|
| 聞き取り | `MediaRecorder` で録音 → 音声をそのまま Gemini へ。聞き取りと返事作りを1回で済ませる |
| 読み上げ | まず iOS 標準の英語音声（Web Speech API の speechSynthesis）。物足りなければ piper の英語モデルを端末内で使う（mana-evo のつくよみちゃんと同じ仕組み） |
| 操作 | 画面下に大きな「おしてはなす」ボタン |
| 注意 | iOS の PWA はマイク許可やオーディオの再生開始にユーザー操作が必要。最初の画面で一度タップしてもらう |

## 7. 続けたくなる仕掛け

- **mana-evo のモンスターが話し相手**。「英語の国から来た」という設定で、話すほど「なかよし度」が上がる
- 1回3〜5分で終わる
- 「今日言えたフレーズ」をシールとして集める
- その日に話した相手モンスターをシール帳に残す

## 8. 保護者の機能

- **保護者画面**：会話ログ（英語＋日本語訳）、今日言えたこと、練習中の言い回し
- **おうち英語カード**：今日の言い回しと、親が家で使えるひとこと
- **親子モード**：親がモンスター役のセリフを読む／親子交代で答える
- **大人モード**：同じ仕組みで大人向けの場面（仕事、旅行、子どもへの声かけ）の会話練習

## 9. mana-evo との連携（段階的に）

1. **今回**：mana-evo のモンスター画像を借りて話し相手にする（mana-evo 側は変更しない）
2. **次の段階**（issue で管理）：Supabase `app-save-hub` を通したデータ連携
   - `app_saves` は `user_id + app_id + slot_id` で分かれているので、同じアカウントでログインすれば英語アプリが mana-evo のセーブ（手持ちモンスターなど）を**読むだけ**で使える
   - 英語アプリは自分の `app_id` に進捗を書き込む
   - 会話のごほうびを mana-evo に渡す場合は、mana-evo 側の仕様変更として先に合意してから実装する（mana-evo の方針どおり）

## 10. 最初に作るもの（MVP）

1. 場面5つ × 言い回し各3つの台本データ
2. モンスター1体との会話画面（録音 → Edge Function → Gemini → 返事を読み上げ。ヒントボタンつき）
3. 今日言えたフレーズの記録（まずは端末内に保存）と、保護者向けの訳表示
4. AI が使えないときの台本モード
5. PWA 化（ホーム画面に追加、オフラインでも台本モードは動く）

1〜2週間子どもに使ってもらい、反応を見てから場面や機能を広げる。

## 11. 技術構成（案）

- フロント：Vite + 素の JS または React（mana-evo に合わせる）、Vercel にデプロイ
- 中継：Supabase Edge Function `english-talk`（Gemini 呼び出し、回数上限）
- 保存：最初は端末内、連携の段階で `app-save-hub` に `app_id = "mana-evo-english"` で保存
