# mana-evo-english コンセプト

最終更新: 2026-10-18（大人モードを追加）

## 1. 目的

- 年長の子どもが、**毎日モンスターと英語でおしゃべり**して、「単語を言える」から「やりとりができる」へ進むこと
- ゴールは「英語って簡単じゃん！外国の人と話してみたい！」と思えるようになること
- 決まりきったやりとりを毎日こなして点数を稼ぐアプリにはしない。**毎回ちがう、自然な会話**をする
- 英語が苦手な保護者も、記録と訳を見ながら**一緒に覚えられる**こと
- mana-evo の英語部分に特化した姉妹アプリとして、モンスターや進捗をつなげていくこと

## 2. 決定事項

| 項目 | 決定 |
|---|---|
| 端末 | iPhone（mana-evo と同じ端末）、ホーム画面に追加する PWA |
| 名前 | リポジトリと URL は `mana-evo-english`。ホーム画面の表示名は短くする（iPhone は長い名前が「…」で切れるため）。案：「マナエボ英語」 |
| AI | Gemini API 無料枠で**上限のない Live モデルだけ**を使う（下の「Live モデルの使い分け」）。Flash-Lite など上限のあるモデルは使わない |
| 1日の上限 | アプリ側では設けない（Live は1日の回数が無制限） |
| 個人情報 | 会話は日常の話題だけ。無料枠の規約（データが改善目的に使われうる）は了承済み |
| モンスター | 可愛い系：**ホワミィ**（m049）／かっこいい最終形：**ニジリュウガ**（m186）。どちらも mana-evo の画像を借りる |
| あだな | 最初の起動時に子どもの呼び名を決める。モンスターが会話の中で呼ぶ。保護者画面で変更可 |
| 保護者画面 | mana-evo と同じ、**4桁の PIN** でロック |
| mana-evo との関係 | 最初はモンスター画像を借りるだけ。Supabase の連携は issue #1 で別途進める |

## 3. 子どもが進む段階とアプリのふるまい

| 段階 | 子どもの状態 | 日本語で答えたとき | 読みの補助 |
|---|---|---|---|
| 1 聞く | Yes/No、指差し | 分かってくれる。返すのは必ず英語 | ひらがな／カタカナ（タップで切替） |
| 2 選ぶ | "Dog or cat?" → "Dog!" | 同上 | 同上 |
| 3 単語 | 単語で答える → 文にして言い直してもらう | 同上 | 同上。慣れたら自動で消える（タップで出せる） |
| 4 型で文 | I like ___ / I want ___ を入れ替える | 同上 | 消える（タップで出せる） |
| 5 自由に（英検3級くらい〜） | 自分で文を作る | **全部英語**。日本語には英語で聞き返す | 発音記号（タップで出せる） |

- 段階は会話の中身（英語で返せた割合、文の長さ）から自動で上がる。保護者画面で手動でも変えられる
- 読みの補助は、英文の下の小さな行をタップするたびに **ひらがな → カタカナ → なし** と切り替わる。子どもが読みやすい方を選べる
- 「慣れたら消す」の判定：同じ言い回しを英語で何度か言えたら、その言い回しの読みは最初から隠す

## 4. モード

モードはデータで定義して、あとから足していける作りにする（7章）。

| モード | 内容 | 最初のリリース |
|---|---|---|
| **おしゃべり** Free Talk | 相棒が自分の出来事や季節の話から話しかけてくる。話題は毎回ちがう | ○ |
| **ごっこあそび** Pretend Play | お店、空港、おいしゃさんなど。場面 × 役割（お客さん／店員さん）× ハプニングで毎回ちがう展開 | ○ |
| **あてっこゲーム** Guess Who? | "Is it big?" "Can it fly?" で、相棒が考えている動物やものを当てる（逆もあり）。段階1〜2でも遊べる | ○ |
| **おはなしづくり** Story Time | 相棒と交代で、1文ずつおはなしを作る | 次の段階 |
| **せかいのともだち** Video Call | 外国の友だちから電話がくる。ネイティブらしい言い回しやアクセントにふれる | **段階4以上で解放**（普通に話せるようになってからのごほうび） |
| 親子モード | 親がモンスター役を読む／親子で交代して答える | ○（保護者画面から） |
| 大人モード | 起動時の「だれが はなす？」から入る大人専用の入り口（11章） | ○ |

## 5. 会話の作り方：AIが会話し、データが方向づける

自然な会話はAIに任せる。データ（シード）は「何について話すか」の種と、「その子に合った難しさ」だけを決める。

### シード（アプリが持つデータ）

- **話題の種**：季節、相棒の出来事（"I found a big pumpkin!"）、食べもの、動物、あそび、きょうの出来事 など
- **場面**（ごっこあそび）：場面ごとの役割、ハプニング、使えそうな言い回しの例
- **相棒の性格**：ホワミィ（ふわふわ、やさしい、甘いもの好き）／ニジリュウガ（元気、冒険好き、ちょっとドジ）
- **段階ごとの話し方のルール**：文の長さ、質問の形（選択式／オープン）、日本語への対応

### AI の役割（Gemini）

- 子どもの返事（音声）を聞き取る。単語だけ、日本語混じり、発音があいまいでもOK
- **言い直して返す**（間違いと言わず、正しい英語で言い返す）
  - 子「きょうりゅう！」→ "Oh, you want to be **a dinosaur**! Roar! That's so cool!"
- 話題がそれても、子どもの興味についていく（自然な会話を優先）
- **相棒の記憶**：子どもが話したこと（好きなもの、なりたいもの、出来事）を少しずつ覚えて、次の会話で聞いてくる
- 応答は JSON で受け取る：

```json
{
  "child_said": "きょうりゅう",
  "child_lang": "ja",
  "reply_en": "Oh, you want to be a dinosaur! Roar! What color is your dinosaur?",
  "reply_kana": "オー、ユー ウォント トゥ ビー ア ダイナソー！ ロアー！ ...",
  "reply_ipa": "",
  "reply_ja": "恐竜になりたいんだね！ガオー！きみの恐竜は何色？",
  "recast": "I want to be a dinosaur.",
  "spoke_english": false,
  "memory": ["wants to be a dinosaur"],
  "hints": [
    { "en": "green", "kana": "グリーン", "emoji": "🟢" },
    { "en": "red", "kana": "レッド", "emoji": "🔴" }
  ],
  "end": false
}
```

- 毎回送るのは「モード・シード・段階のルール・相棒の記憶・直近の数往復」だけ

### Live モデルの使い分け（すべて無料枠で上限なし）

| 役割 | 1番目 | 2番目 | 3番目 | 理由 |
|---|---|---|---|---|
| 相棒との会話（声） | Gemini 3 Flash Live | Gemini 3.8 Live | Gemini 2.5 Flash Native Audio Dialog | 会話は速さが一番。3.8 は賢いが遅い可能性、2.5 は声の会話専用の最後の予備 |
| 読み・ひらがなの意味・ヒント・言い直し・記憶 | 裏方の Live（Gemini 3.8 Live、音は鳴らさない）が関数 show_card だけを呼ぶ | 同じく Gemini 3 Flash Live | – | Live は文字だけの返事（TEXT）に対応していない。会話中の相棒に頼むと会話を優先して呼ばないので、仕事をひとつにした裏方に任せる |
| 子どもの言葉の聞き取り | Gemini 3.5 Transcribe Live（文字起こし専用。確定した文字を相棒に渡す） | 会話中の Live に声をそのまま送る（英語・日本語に限定＋よく出る単語を優先） | – | 子どものカタカナ英語（チーズ）を相棒が聞きまちがえる（chili）のを防ぐ |
| 使わない | Gemini 3.8 Live Extended Thinking | Gemini 3.5 Live Translate | – | 会話には遅すぎる／通訳専用。Extended Thinking は保護者向けのまとめに使う余地あり |

- 相棒の声の AudioContext はひとつだけ（Live の接続ごとに作らない。裏方・文字起こしは音にさわらない）。マイクは別の AudioContext（共用にすると、読み上げなどで止められたときに声とマイクが一緒に止まる）。止められたら作りなおす
- 「話しはじめ／話し終わり」は音を送ったときだけ送る（中身のない発話を送ると Live が 1007 で接続を切る）
- 相棒の声は AudioWorklet の中にためて1本の音として流す（細切れのつなぎ目なし）。話しはじめ 0.5 秒、とぎれたら小さくして止め、0.4 秒たまってから再開（iPhone では声が 0.3 秒ほどの細切れで届く）。とぎれた回数はログ（audio-gaps）に残す。文字の描きなおしは 0.15 秒ごとにまとめる
- 相棒の1回の発話は段階ごとの語数上限（段階1は10語）を守り、言わせる練習（Can you say...?）はしない
- 相棒には「カタカナ英語として聞く」「自信がなければ『Cheese? Or chili?』と聞き返す」と指示する

### Live（リアルタイム会話）のしくみ

- english-talk が Gemini の使い捨て接続キー（1回だけ・30分）を発行し、ブラウザが Live API に直接つなぐ。API キーはブラウザに渡さない
- 子どもは「おしながら はなす」。押している間の声をそのまま流し、離したら相棒がすぐ声で返事をする（自動の音声検出は使わず、相棒の声で勝手に割り込まれないようにする）
- 相棒の声は Gemini の自然な声。キャラごとに声の演技指示（ホワミィ：高く甘くふわっと／ニジリュウガ：低く力強くおどけた）を入れ、「なかま」画面で候補の声を聞き比べて選べる（初期：Leda／Puck）。話している途中でボタンを押すと止まって聞いてくれる
- 子どもの言葉と相棒の言葉は文字起こしで画面に出す。1往復ごとに、文字だけで返す Live の接続で、読み・日本語の意味（ひらがな）・ヒント・言い直し・記憶を付ける。子どもの言葉の聞きまちがい（「ちゃ」など）も、相棒の返事から推測して直す。これが失敗しても会話は止めない
- Live のモデルは、使えるものの中から「3 Flash Live」→「3.8 Live」の順で自動で選ぶ（速さ優先）。1つ目でつながらなければもう1つで試す。保護者画面の設定で固定もできる（`GEMINI_LIVE_MODEL` で固定も可）

### Live につながらないとき

- Live の接続は2〜3分で向こうから切られる（1008）。切れた瞬間に話すと、聞きまちがい（文字起こしが使えず相棒が音から推測する）や返事の途中で止まる原因になる
- そこで、つないで100秒たったら、話していないすきに新しい接続へ入れかえる（相棒は続きの目印で会話の流れを引きつぐ。文字起こし・裏方も同じ）
- 返事の途中で8秒なにも届かなければ、その往復を終わったことにして画面を止めない

- 会話の途中で切れたら、これまでの会話を渡して Live につなぎなおす（2回まで）
- それでもだめなら「つながらなかったよ」と出して、もういちど試せるようにする（上限のあるモデルには切り替えない）

## 6. 声まわり（iPhone PWA）

| | 方針 |
|---|---|
| 聞き取り | 「おしながら はなす」。Live では 16kHz の PCM を押している間ずっと流す。予備の方式では 16kHz の WAV を1回で送る |
| 読み上げ | Live では Gemini の声（24kHz）。予備の方式では iOS 標準の英語音声（相棒ごとに高さと速さを変える） |
| 文字入力 | 大人の練習や、声が出しにくいとき用にキーボード入力も用意 |
| 注意 | iOS の PWA はマイク許可や音の再生開始にタップが必要。最初の画面で一度タップしてもらう |

## 7. バリエーションを増やす仕組み

- モード、話題の種、場面、ハプニング、相棒の性格を **データファイル** で持つ
- 会話の指示文はこれらを組み合わせて毎回作る → 組み合わせの数だけ会話が変わる
- 新しい場面を足すときは、データを1つ追加するだけでよい
- 新しい相棒も、mana-evo の画像と性格データを足せば増やせる（Supabase 連携後は、mana-evo で捕まえたモンスターから選べるようにする）

## 8. 続けたくなる仕掛け

- 相棒が**自分から話しかけてくる**（毎回ちがう話題）
- 相棒が**子どもの話を覚えていて**、次に聞いてくる
- 「なかよし度」が上がる
- 「きょう いえた えいご」を褒める。はじめて言えた表現には印がつく
- シールを集める

## 9. 保護者の機能

- **会話ログ**（英語＋日本語訳、英語で返せたか／日本語を言い直してもらったか）
- **いまの段階**と、手動での変更
- **おうち英語カード**：今日の会話から、家で使えるひとこと
- **親子モード**、**大人の練習**
- あだなの変更、PIN の変更

## 10. 技術構成

- フロント：Vite + React（mana-evo に合わせる）、PWA、Vercel にデプロイ
- 中継：Supabase Edge Function `english-talk`（app-save-hub プロジェクト）
  - Gemini の API キーは Edge Function の secret に置き、アプリには入れない
  - ログイン（mana-evo と同じアカウント、メールとパスワード）した人だけが使える
  - モデルの切り替え（3.1 → 3.5 → おしまい）も中継側で行う
- 保存：最初は端末内。連携の段階で `app-save-hub` に `app_id = "mana-evo-english"` で保存（issue #1）

## 11. 大人モード

同じアプリの中で入り口を分ける。起動したら「だれが はなす？」で子ども／大人を選ぶ（大人が1人もいなければ子どものホームから始まり、保護者画面の「大人モードへ」から作る）。大人側は落ち着いた濃い色。

| 項目 | 決定 |
|---|---|
| 相棒 | ロンドン出身の友だち **Alex**（声は Charon）。先生ではなく友だちとして話し、グチも聞く。言い直しは会話の中でさりげなく |
| 大人の人数 | 何人でも（パパ・ママなど）。人ごとに記憶・カード・TOEIC の記録を分ける |
| PIN | 大人側に入るときは保護者PIN（設定でオフにできる） |
| 保存 | 端末内（`mee-adult-v1`）。大人の記憶は子ども側に出さない |
| TOEIC | 目標スコアは人ごとに設定（初期 730） |

### 有料アプリのいいとこ取り

| もとのアプリ | 取り入れたこと |
|---|---|
| Speak / Praktika / ネイティブキャンプ | Alex との雑談。言い方のコツ（💡）と言い直し（💬）を、会話を止めずに出す |
| Santa / Duolingo | **きょうのメニュー**（15分／5分だけ）。復習の量と苦手で中身が変わる |
| ELSA / Speak | **シャドーイング**。言えた単語は緑、あやしい単語は黄色、点数と発音のコツ |
| abceed / スタディサプリ | お手本を ふつう／ゆっくり／2回 で聞ける |
| Mikan / Anki | 会話で出た言い方が自動で**復習カード**になる。わからない＝10分後、あやしい＝あした、言えた＝4日後（以降 2.5倍） |
| Santa / スタディサプリ | **TOEIC 実力診断**（10問）→ 予想スコア（めやす）・パートごとの正答率・苦手トップ3 → 苦手つぶし |
| Duolingo Max | 問題ごとに「なぜ正解か・ひっかけ」を一言で |
| どれにもない強み | 仕事・家族・グチを覚えていて、次の雑談で続きを聞く。その日の会話から言い直しと TOEIC 問題を作る |

### 流れ

- ホーム：Alex が前回の記憶から話しかける（タップで読み上げ）。きょうのメニュー、コース（雑談して最後にお勉強／雑談だけ／TOEIC／仕事／子どもへの声かけ／復習カード／シャドーイング／旅行／TOEIC の話題で雑談）、記憶とカードの一覧
- 雑談して最後にお勉強：雑談 8分 → 時間が来たら Alex がまとめ、「お勉強へ」→ きょうの言い直し → TOEIC ミニ問題 4問 → きょうのまとめ
- きょうのまとめ：時間・話した文・正解数・覚えたい言い方・Alex が覚えたこと（ひとつずつ消せる）・予想スコア

### しくみ（すべて上限のない Live の中だけ）

- 雑談：子どもと同じ Live の会話（Alex の人柄・大人の記憶・復習中の言い方・TOEIC の苦手を指示に入れる）
- 画面カード：大人用の裏方が show_card で 訳・言い直し・コツ・覚えたい言い方（learn）・記憶（work/family/hobby/feeling/other）を返す
- TOEIC 問題：音を鳴らさない Live に関数 make_questions で作ってもらう（公式と同じ形式のオリジナル）。作れなかった分は予備の問題から
- 発音のコツ：音を鳴らさない Live に関数 pron_tips で
- 声の答え（復習・シャドーイング・TOEIC）：3.5 Transcribe Live で文字にして判定
- 予想スコアは正答率から出す目安（8問以上といてから表示）
