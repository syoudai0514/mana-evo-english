## 再開とレビュー

1. この表、`docs/CONTENT_REPORT.json`、GitHubの本PRと各Issueの更新を読む。
2. `git status` と直近コミットを確認。既存の758教材・600問を再生成しない。IDを維持して修正する。
3. `npm ci && npm test && npm run build`、`npm run test:e2e`。この環境では `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium` を付ける。
4. `node scripts/content-report.mjs` で実数・権利・画像SHAを更新。AI生成だけで `review.status=reviewed` にしない。
5. 実機・実アカウント・独立言語レビューの結果をIssueごとに記録してからcloseする。自動close用の `Closes` は付けない。

## Backendの適用済み変更

- 対象は既存 `app-save-hub` (`wdwbmvpipbdpomqulsrj`)。別プロジェクトへ移行していない。
- `20261022043554_english_live_guard.sql` を適用。privateのlease/rate tablesとservice-role専用RPC。8同時接続、240 token発行/時、200診断/時、lease10分。診断は許可したstep・数値code・platformに限定し、本文やトークンはブラウザから送信しない。
- DB transaction内で8接続成功/9接続目拒否、release後再取得、anon/authenticatedのRPC実行不可を確認（テストtransactionはrollback）。
- 新規 `english-talk-v2` version2をJWT必須でdeploy。既存 `english-talk` は変更していない。未認証401とOPTIONS200を実確認。
- クライアントはv2へ接続する。トークンはmodel field mask/単回利用/期限付き。閉じたleaseを解放し、取りこぼしはTTLで回収。
- 既存DB advisorの漏えいパスワード保護OFF警告は従前から存在する。共有Auth設定を勝手に変更していない。

## 誤解しないための区別

- 「端末TTSで再生可能」「AIで保存音声を作成可能」「収録済み音声あり」は別。最後のものは今回0。
- 音声生成の低速は読み手への速度指定。聴取レビュー前に速度/品質が一定だと保証しない。
- 教材の `estimatedMinutes` は目安。全音声の実測時間ではない。
- 新しい教材・TOEICは全件draft。ライブラリにもレビュー中と表示。公式教材・認定CEFR・校正済み得点予測ではない。
- フロントエンドは作業ブランチ。mainへのマージ前は既存の本番画面には出ない。
